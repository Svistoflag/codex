# Trap Detections Web

Веб-приложение для сбора и просмотра фото/видео детекций фотоловушек через почту.

## Возможности
- Подключение нескольких фотоловушек (email-адресов).
- Автоматический сбор вложений через IMAP.
- Просмотр детекций (фото и видео), скачивание и шаринг.
- Базовая интерпретация содержимого и теги объектов.
- Уведомления о новых данных (через браузер).
- Фильтры по типам объектов и типу медиа.

## Быстрый старт
```bash
npm install
npm start
```
Откройте `http://localhost:3000`.

## Переменные окружения
Создайте `.env`:
```
PORT=3000
POLL_INTERVAL_MS=30000
DEFAULT_TRAP_EMAIL=trap@example.com
EMAIL_HOST=imap.yandex.ru
EMAIL_PORT=993
EMAIL_SECURE=true
EMAIL_USER=example@yandex.ru
EMAIL_PASS=app-password
```

## Примечания
- Приложение использует IMAP для чтения новых писем и сохраняет вложения в `storage/`.
- Для анализа используется эвристика по названию файлов. Можно заменить на ML-модель.
